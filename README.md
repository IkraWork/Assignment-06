# 💪 B14-A6-Fit Log

FitLog is a dark, no-nonsense gym companion application. It allows you to pick a lift, lock it into today's plan, and watch the week's work add up. Train with intent and log every set.

## 🛠️ Technologies Used
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Lucide React Icons
- React Hot Toast
- localStorage (for data persistence)

## ✨ Key Features
1. **Browse Workout Library**: View a responsive grid of 12 workouts fetched from an external API, complete with images, categories, and key stats.
2. **Sort Workouts**: Easily sort the library by Duration, Calories Burned, or Rating using a sleek dropdown.
3. **Detailed Workout Views**: Navigate to dynamic detail pages that showcase large images, key specifications, and step-by-step instructions.
4. **My Plan & Saved Tabs**: Add up to 5 lifts to your "Today's Plan", or save workouts for later. View real-time aggregated metrics for exercises, minutes, and calories.
5. **Interactive Actions**: Mark your planned workouts as done or remove them, with instant UI updates and toast notifications confirming your actions. State persists across reloads via localStorage.
